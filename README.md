# Vecipets

## Overview

Vecipets is a **Next.js** frontend with a NestJS backend. The repository contains the source code for the frontend application located in `apps/frontend`.

## Getting Started (Frontend)

```bash
# Clone the repository (if you haven't already)
git clone https://github.com/MaximilianoMOM/Vecipets.git
cd Vecipets

# Install dependencies
cd apps/frontend
npm install
```

### Running the Development Server

```bash
npm run dev
```

The command will generate the `.next` folder automatically. This folder contains the compiled build artifacts used by Next.js during development and production.

## Building the Production Output

```bash
npm run build   # creates a production‑ready .next folder
```

### Important Note about the `.next` Folder

- The `.next` directory is **generated** by Next.js; it should **not** be committed to the repository.
- It is listed in `.gitignore` (line 10) to prevent accidental commits.
- When sharing the project, **do not** push the `.next` folder. Others can recreate it by running `npm install` followed by `npm run dev` or `npm run build`.
- If you need to distribute the built files (e.g., for a demo), you can create a separate build branch, temporarily remove the `.next` entry from `.gitignore`, commit the folder, and then delete that branch after use.
