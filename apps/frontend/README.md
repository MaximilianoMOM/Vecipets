# VeciPets Frontend Web (Next.js 16 + React 19 + Tailwind CSS + Leaflet)

Aplicación Web para la plataforma **VeciPets**.

## 🚀 Requisitos e Instalación

Para ver la guía completa paso a paso de todo el proyecto, consulta el [README principal en la raíz](../../README.md).

### Instalación Rápida
```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev

# 3. Compilar para producción
npm run build
```

### 🔑 Rutas Principales
* **Página de Inicio:** `http://localhost:3000/`
* **Inicio de Sesión:** `http://localhost:3000/login`
* **Registro de Usuarios:** `http://localhost:3000/registro`
* **Mapa Explorador:** `http://localhost:3000/mapa`
* **Catálogo de Reportes:** `http://localhost:3000/reportes`
